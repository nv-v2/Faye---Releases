# Faye

Aplicación de escritorio para centrales de monitoreo que registra el reporte horario de cada turno.

## Qué hace

- Durante el turno, cada hora le pide al operador un reporte: Sin Novedad o Con Novedad, con una observación.
- Al terminar el turno pide un reporte de cierre.
- Si el operador no responde a tiempo, queda registrado.
- Al terminar cada turno envía un resumen por correo.
- Las opciones de configuración están protegidas con PIN.
- Se actualiza desde el mismo programa.
